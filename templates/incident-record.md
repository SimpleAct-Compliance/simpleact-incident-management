Zum Ausfüllen. Die kursiven Hinweise erklären, warum ein Feld gebraucht wird — sie können beim Übernehmen entfallen.

## 2. Zeitpunkte

| | Datum, Uhrzeit | Quelle der Angabe |
|---|---|---|
| Vorfall eingetreten | | |

| **Kenntnis der verantwortlichen Stelle** | | |

*Meldefristen laufen ab Kenntnis, nicht ab Eintritt. Ohne diesen Zeitpunkt lässt sich die Fristwahrung nicht belegen — und die Beweislast liegt bei Ihnen.*

## 3. Einstufung

| Frage | Antwort | Begründung |
|---|---|---|
| Schweregrad | Hinweis / Warnung / Hoch / Kritisch | |
| **Schwerwiegender Vorfall nach Art. 73?** | ja / nein | |
| **Datenschutzverletzung nach Art. 33 DSGVO?** | ja / nein | |
| Meldepflicht ausgelöst? | ja / nein | |

*Die beiden Einstufungen werden getrennt beantwortet. Ein Vorfall kann beides sein, eines von beidem oder keines. Auch ein Nein gehört begründet — eine begründete Nicht-Meldung ist verteidigbar, eine unbegründete nicht.*

## 4. Hergang

*Was ist geschehen, in welcher Reihenfolge? Wer war betroffen? Sind auf Grundlage des fehlerhaften Verhaltens Entscheidungen über Menschen getroffen worden, und wenn ja, wie viele?*

## 7. Ursachenanalyse

*Nicht der erste plausible Grund, sondern der Grund, der erklärt, warum es nicht früher aufgefallen ist. Wenn die Antwort lautet „wir haben nicht darauf geschaut", ist das eine Erkenntnis über das Monitoring, nicht über das Modell.*

## 8. Korrekturmaßnahmen

| Maßnahme | Verantwortlich | Fällig | Status | Wirksamkeit bestätigt |
|---|---|---|---|---|
| | | | | |

*Der letzte Spalteneintrag ist der, der am häufigsten leer bleibt. Eine Maßnahme ohne bestätigte Wirkung ist eine Absicht.*
